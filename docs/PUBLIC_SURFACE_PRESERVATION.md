# Public-Surface Preservation Gate

A public page is not its copy. Before a wholesale semantic rewrite, inventory and
preserve its background/motion, assets, navigation, instrumentation, structured
data, accessibility, and responsive behaviour.

Any intentional removal must be named in the diff and commit message. Run the
browser smoke suite before and after the rewrite; canvas presence alone is not
proof (record its renderer and sample pixels), and image markup alone is not proof
(verify successful decoding). Re-observe production after deployment. Keep
report-only CSP findings, network failures, and enforced CSP blocks classified
separately.
