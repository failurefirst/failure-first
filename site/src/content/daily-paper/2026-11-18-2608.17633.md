### 1. Introduction: The Open-Vocabulary Double-Edged Sword

Integrating open-vocabulary vision-language models (VLMs) into 3D metric-semantic mapping represents a double-edged sword for spatial intelligence. On one hand, open-vocabulary detectors overcome the strict boundary limits of traditional closed-set systems, enabling autonomous agents to recognize long-tail semantic categories and fine-grained objects overlooked by fixed taxonomies. On the other hand, incorporating unconstrained 2D VLM detections directly into 3D representations introduces severe spatial failure modes. Unfiltered VLM detections frequently fragment continuous surfaces (such as walls or large tables) into disconnected semantic patches and suffer from asymmetric containment—a structural failure where small, fine-grained objects (e.g., wall plugs, switches, or small decor) are merged wholesale into neighboring background structures.

To solve these perceptual failure modes, Hao et al. (comprising researchers from AgiBot and Xi'an Jiaotong University) developed **OVIP-SG** (Open-Vocabulary Instance-Preserving Scene Graphs). Failure First reports on this framework, which establishes a unified methodology for high-fidelity 3D mapping, functional layout partitioning, and small-object retrieval. Beyond resolving instance-level boundary degradation during map building, OVIP-SG directly addresses a critical failure mode in embodied navigation: agents searching endlessly for missing items due to an inability to confirm object absence.

> **Research Overview & Key Mitigations**
> - **Primary System:** OVIP-SG (Open-Vocabulary Instance-Preserving Scene Graphs), introduced by Hao et al. (AgiBot / Xi'an Jiaotong University).
> - **Addressed Failure Modes:** (1) Asymmetric containment (over-merging fine-grained objects into background furniture), (2) surface fragmentation across continuous structures, (3) semantic vector corruption caused by peripheral or truncated camera crops, and (4) infinite search loops in embodied agents caused by missing target-absence classification logic.
> - **Core Innovations:** Frame-Adaptive Vocabulary Gate (FAV-Gate), Instance-Preserving Association (IPA using IPSM and LAMP), Area-Weighted Fusion (AWF), Knowledge-Guided Semantic Watershed (KGSW), and Cascaded Active Retrieval with Absence Assessment (CARA).

### 2. Task A Architecture: Instance-Preserving Semantic Mapping & Partitioning

The mapping architecture of OVIP-SG is structured around preserving structural instance fidelity and maintaining clean semantic boundaries during online 3D scene graph construction.

```
       +-------------------------------------------------------+
       |             Perception Front-End (E2G)                |
       |  VLM Candidate Enumeration + FAV-Gate Filtering       |
       |  LocateAnything 2D Grounding + SAM2 Mask Extraction   |
       +---------------------------+---------------------------+
                                   |
                                   v
       +-------------------------------------------------------+
       |         Instance-Preserving Association (IPA)         |
       |  - IPSM: Symmetric 3D-IoU Spatial Term                |
       |  - LAMP: Label-Aware Merge Penalty                    |
       +---------------------------+---------------------------+
                                   |
                                   v
       +-------------------------------------------------------+
       |             View-Area Feature Fusion (AWF)            |
       |  Online Area & Center-Distance Weighted CLIP Update   |
       +---------------------------+---------------------------+
                                   |
                                   v
       +-------------------------------------------------------+
       |     Knowledge-Guided Semantic Watershed (KGSW)        |
       |  Distance Fields + VLM Functional Grouping Seeds      |
       +-------------------------------------------------------+
```

#### 2.1 Open-Vocabulary Perception (E2G & FAV-Gate)
OVIP-SG processes posed RGB-D frames using an *Enumerate-to-Ground* (E2G) front-end coupled with a *Frame-Adaptive Vocabulary Gate* (FAV-Gate):
- **E2G Pipeline:** For each incoming RGB-D frame, a cloud VLM (such as Kimi-k2.6) enumerates visible candidate object types $T^t$. LocateAnything predicts 2D bounding boxes, SAM2 refines the 2D segmentations, and CLIP extracts visual feature vectors ($f_i$). Cloud VLM calls are reserved specifically for fine-grained semantic decisions, while routine geometric updates run on-device.
- **FAV-Gate Mechanics:** Direct VLM enumeration generates sporadic single-frame hallucinations that cause false 3D detections. FAV-Gate eliminates these noise sources by building a stable global vocabulary $V_{\text{glob}}$ containing only terms that recur in at least $n_{\text{min}} \ge 3$ frames, minus an explicit blacklist $B$ (e.g., text, logos, pipes). Per frame, the system queries the grounder with the intersection:
  $$V^t = T^t \cap V_{\text{glob}}, \quad V_{\text{glob}} = \{ w : \text{freq}(w) \ge n_{\text{min}} \} \setminus B$$

#### 2.2 Protecting Small Instances (IPA: IPSM + LAMP)
When mapping fine-grained elements, standard 3D association algorithms evaluate single-directional spatial containment ($\text{Vol}(b_i \cap B_j) / \text{Vol}(b_i)$). Because a small object box $b_i$ lies entirely within the bounding volume of an enclosing table or wall $B_j$, containment metrics yield a score of $1.0$, causing the small item to be absorbed into the larger structure.

The *Instance-Preserving Association* (IPA) pipeline resolves this issue using a composite pairwise affinity score $\tilde{\phi}_{ij}$ to evaluate detection $d_i$ against existing scene graph node $o_j$:
$$\tilde{\phi}_{ij} = (1 + \alpha) \frac{\text{Vol}(b_i \cap B_j)}{\text{Vol}(b_i \cup B_j)} + (1 - \alpha) \cos(f_i, g_j) - w_L \mathbb{1}[\ell_i \neq \text{mode}(C_j)]$$

IPA operates through two primary mechanisms within this formulation:
1. **Instance-Preserving Symmetric-IoU Merge (IPSM):** IPSM replaces one-way containment with symmetric 3D Intersection over Union ($\text{Vol}(b_i \cap B_j) / \text{Vol}(b_i \cup B_j)$), balanced against visual feature cosine similarity via hyperparameter $\alpha$. If $b_i \subseteq B_j$, the spatial term evaluates to $\text{Vol}(b_i) / \text{Vol}(B_j)$, preventing asymmetric absorption.
2. **Label-Aware Merge Penalty (LAMP):** LAMP subtracts a penalty weight $w_L$ (set to $0.5$ in implementation) whenever candidate label $\ell_i$ diverges from the existing instance's majority class history $\text{mode}(C_j)$. This protects fine-grained attached items (e.g., wall switches, power outlets, vases, picture frames) from being absorbed into surrounding surfaces.

The decision rule assigns candidate detection $d_i$ to existing instance $j^\star = \arg\max_j \tilde{\phi}_{ij}$ whenever $\tilde{\phi}_{ij^\star} > \tau$; otherwise, $d_i$ initializes a new object node in the scene graph.

#### 2.3 View-Area Feature Fusion (AWF)
Standard mapping pipelines update instance CLIP features by computing equal-count running averages over incoming 2D box crops. This approach allows off-axis, highly truncated, or tiny peripheral detections to corrupt the semantic visual representation of an object. *Area-Weighted Fusion* (AWF) updates instance feature vectors $g_j$ online by weighting detection features $f_k$ according to resolution-normalized 2D bounding box area ($a_k / HW$) and clearance from the image center $p_0 = (W/2, H/2)$:
$$w_k = \frac{a_k}{HW} \exp \left( -\frac{2 \|p_k - p_0\|_2^2}{\sigma_v^2 (W^2 + H^2)} \right), \quad \sigma_v = 0.6$$

Online accumulators update instance feature $g_j$ without storing past image frames:
$$S_j \leftarrow S_j + w_k f_k, \quad \Omega_j \leftarrow \Omega_j + w_k, \quad g_j = \frac{S_j}{\|S_j\|_2}$$

Normalized accumulation ensures large, centered observations dominate the semantic embedding space while remaining invariant to camera image resolution.

#### 2.4 Knowledge-Guided Semantic Watershed (KGSW)
Geometric-only room segmentation algorithms fail in open-plan or elongated indoor spaces where structural walls do not demarcate functional boundaries. *Knowledge-Guided Semantic Watershed* (KGSW) projects free space $F$ and object centroids onto a $0.05\text{ m}$ bird's-eye-view (BEV) grid to construct a clearance distance field $D(\mathbf{x}) = \min_{\mathbf{y} \notin F} \|\mathbf{x} - \mathbf{y}\|_2$.

Morphological wall dilation ($\text{DIL} = 6$) establishes structural geometric cores $C_0$. To partition open-plan layouts, KGSW utilizes VLM-inferred functional object types $t_i$. Mixed-function open cores containing objects of multiple functional types are partitioned via DBSCAN spatial clustering ($\text{DB}_\epsilon$, with neighborhood radius $\epsilon = 2.0\text{ m}$). Seed markers of radius $r = 0.30\text{ m}$ are placed at object cluster locations to guide a distance-field watershed expansion, generating compact functional search regions while enforcing a minimum core area threshold $A_{\text{min}}$.

| Component Acronym | Full Name | Primary Mitigation Function |
| :--- | :--- | :--- |
| **E2G** | Enumerate-to-Ground | Leverages VLM open-world naming alongside LocateAnything, SAM2, and CLIP for 2D candidate grounding. |
| **FAV-Gate** | Frame-Adaptive Vocabulary Gate | Filters sporadic single-frame VLM hallucinations using a frequency floor ($n_{\text{min}} \ge 3$) and blacklist filtering. |
| **IPA** | Instance-Preserving Association | Combines IPSM and LAMP to prevent structural over-merging of small objects into background instances. |
| **IPSM** | Instance-Preserving Symmetric-IoU Merge | Replaces one-way containment metrics with symmetric 3D IoU to protect independent small object volumes. |
| **LAMP** | Label-Aware Merge Penalty | Applies a spatial-semantic penalty ($w_L = 0.5$) during association to protect small attached objects (e.g., wall plugs, switches). |
| **AWF** | Area-Weighted Fusion | Weights online CLIP vector fusion by normalized surface area and center distance to suppress peripheral crop noise. |
| **KGSW** | Knowledge-Guided Semantic Watershed | Subdivides open floor plans into compact functional regions using clearance fields and VLM functional grouping. |

### 3. Task B Mechanics: Cascaded Active Retrieval with Absence Assessment (CARA)

To ground free-form natural language queries to 3D spatial target locations without wasting computational or operational resources, OVIP-SG implements **Cascaded Active Retrieval with Absence Assessment (CARA)**. The framework executes a 4-tier escalation cascade, invoking more expensive exploration stages only when cheaper, localized evidence is unavailable or rejected.

1. **Tier 1 (Map Lookup):** The system attempts direct matching between the text query and existing high-fidelity 3D scene graph nodes by class name string match or CLIP text-vector similarity. If a confident candidate exists on the map, CARA directly returns its 3D centroid. This tier issues zero VLM calls.
2. **Tier 2 (2D-Tag Retrieval):** If the target is absent from the 3D map but carried 2D tag priors in historical camera frames, CARA searches the frame tag memory. CLIP scores the query against stored 2D tag features, contiguous high-scoring frame sequences are bridged into candidate temporal segments, and a VLM performs fine-grained attribute disambiguation on the candidate frame (e.g., distinguishing a "floral towel" from plain towels).
3. **Tier 3 (History-Frame VVC):** When targets lack prior 2D tags, a VLM selects target region priors based on soft commonsense constraints ($S(\text{goal} | r)$). A grounder re-processes stored raw history RGB-D frames corresponding to those regions. Candidate detections are back-projected into $0.25\text{ m}$ 3D spatial voxels via **Voxel-Vote Confirmation (VVC)**. Voxels receiving multi-view consensus across $\ge k$ frames ($k \ge 3$) undergo final VLM crop verification to confirm target presence and reject false positives.
4. **Tier 4 (Active Search & Coverage-Conditioned $\emptyset$-Decision):** If historical frame re-detection yields no candidates, the robot executes physical active search. The agent samples navigation waypoints maintaining clearance greater than the robot radius (excluding known object footprints) and navigates using shortest paths on the floor-room graph. At each waypoint, the robot rotates through six $60^\circ$ headings to capture fresh RGB-D imagery (rendered at $512 \times 512$ pixels). Region visitation order balances VLM functional priors against normalized geodesic distance:
   $$r^\star = \arg\max_{r \in \mathcal{R}} \left[ \lambda S(\text{goal} | r) - (1 - \lambda) \frac{g(p_{\text{cur}}, c_r)}{d_{\text{max}}} \right]$$
   Crucially, if the agent completes physical coverage across all reachable search viewpoints without generating any VLM-verified voxel candidates, CARA terminates exploration and outputs a formal **coverage-conditioned negative decision ($\emptyset$-decision)** rather than searching indefinitely.

### 4. Empirical Evaluation & Quantitative Results

Hao et al. evaluated OVIP-SG across synthetic and real-world benchmarks, including Replica, ReplicaCAD, HM3D (evaluated in Habitat), and physical deployments on humanoid hardware.

#### 4.1 Mapping Fidelity & Component Ablations on Replica
Evaluated across six Replica scenes under a standardized per-scene protocol ($52$ classes, $k=1$ nearest neighbor, standard CLIP text prompt template `"A photo of a {label}."`), OVIP-SG achieved marked performance gains:
- **Semantic Mapping Accuracy:** OVIP-SG achieved a **+6.31 point mAcc improvement** ($51.31\%$ vs. $45.00\%$) and a **+5.15 point F-mIoU improvement** ($61.45\%$ vs. $56.30\%$) over ConceptGraphs.
- **Native Instance Quality:** Evaluated against official face-level Replica mesh object IDs at $\text{IoU} > 0.5$, OVIP-SG achieved a class-agnostic Panoptic Quality (PQ) of **0.398** (compared to 0.338 for ConceptGraphs and 0.163 for HOV-SG), alongside Segmentation Quality (SQ: 0.776) and Recognition Quality (RQ: 0.514).
- **Small Instance Preservation:** In small-tercile surface area evaluation, OVIP-SG achieved a small-instance recall of **0.254** (vs. 0.164 for ConceptGraphs). Targeted swallowed-class recall (e.g., wall plugs, tissue boxes, small vases) increased from $15.8\%$ to $43.2\%$ following the introduction of IPSM+LAMP.

#### 4.4 Real-Robot Deployment
Hao et al. deployed the complete OVIP-SG mapping and CARA retrieval stack online and in closed-loop on an **AgiBot Expedition A3 humanoid robot** operating in physical office and hotel environments. Synchronized sensor streams allowed the A3 humanoid to incrementally map indoor scenes, parse free-form language service requests (e.g., "Go check in", "I want to rest", "I want dessert"), locate target 3D bounding coordinates, and physically navigate to destination goals using its native motion control stack. On real-robot small-object retrieval tasks, OVIP-SG improved navigation success rate over FSR-VLN by 0.08.

### 5. Research Takeaways & Safety Implications

- **Symmetric Spatial Metrics Prevent Structural Object Loss:** Asymmetric containment metrics in 3D mapping create a systematic visual failure mode where small items located on or inside furniture are absorbed into background structures. Replacing containment with symmetric 3D IoU (IPSM) and label-aware penalties (LAMP) preserves fine-grained objects as independent, queryable 3D scene graph nodes.
- **Coverage-Conditioned Negative Decisions Stop Endless Search Loops:** Autonomous agents operating under open-world assumptions often fail by searching indefinitely when queried items are absent. By coupling physical exploration graph traversal with multi-view voxel voting (VVC), CARA establishes a formal mechanism for issuing coverage-conditioned $\emptyset$-decisions, providing an empirical baseline for safe search termination.
- **View-Area Weighting Protects Semantic Vector Integrity:** Count-averaged feature fusion allows peripheral or severely truncated visual crops to corrupt visual embeddings over time. Weighting online CLIP feature vectors by resolution-normalized bounding box area and center distance preserves label purity across long temporal sequences without requiring continuous cloud VLM re-inference.
- **Benchmark Annotations Limit Open-World Evaluation:** Audit results from Tier-4 absence testing indicate that open-world negative decision accuracy is bounded by dataset annotation completeness. All eight strict false positives produced by CARA contained target-like physical objects missing from ground-truth annotations, highlighting the need for complete annotations in future embodied AI safety benchmarks.
