### 1. Introduction: The Risk of Ungated Memory Updates

Autonomous mobile robots operating in fluid, oceanic, or GPS-denied environments must continuously stream local sensory observations into global spatial memory. However, under degraded sensing and persistent odometric drift, writing local predictions directly into a global map introduces a subtle but destructive failure mode: **silent streaming memory corruption**. When spatial observations are locally ambiguous, streaming updates unconditionally causes errors to compound over time, corrupting global memory with persistent artifacts.

In their paper *"Write-Safe Flow Field Mapping under Ambiguous Onboard Sensing and Localization Drift"*, Jin et al. (2026) investigate this failure mode within underwater flow field mapping. The authors establish a critical thesis for autonomous memory management: when alignment with global context is uncertain, deciding **whether to write** to a global map is just as vital as deciding **what to predict**. Without explicit write-safety mechanisms, streaming memory architectures lack a way to reject misregistered updates, leading to self-reinforcing map corruption that degrades downstream navigation and state estimation.

---

### 2. The Failure Mode: Observation Aliasing and Localization Drift

The accumulation of false mapping artifacts—termed **ghost structures** by Jin et al.—stems from two compounding environmental and operational factors:

1. **Observation Aliasing**: Spatial non-uniqueness where distinct physical locations yield identical local sensory signatures. In fluid environments, coherent, symmetric, or repeating hydrodynamic flow features produce identical local pressure and velocity profile readings across different spatial regions.
2. **Localization Drift**: Mobile field and underwater robots relying on dead reckoning inevitably accumulate positional drift over time. The true physical pose $p^\star_t$ diverges from the reported odometric pose $\hat{p}_t = p^\star_t + \eta_t$, where $\eta_t$ represents accumulated spatial error.

```
+-----------------------------------------------------------------------------------+
|                            MECHANISM OF MAP CORRUPTION                            |
|                                                                                   |
|  [Aliased Local Observation] + [Localization Drift: p̂_t = p*t + η_t]               |
|                                         │                                         |
|                                         ▼                                         |
|                       [Misregistered Memory Update Write-In]                      |
|                                         │                                         |
|                                         ▼                                         |
|                     [Persistent "Ghost Structure" Formation]                      |
|                                         │                                         |
|                                         ▼                                         |
|            [Corrupted Global Map Used as Faulty Reference for Next Step]         |
+-----------------------------------------------------------------------------------+
```

When local flow predictions are written at the drifted reported pose $\hat{p}_t$, locally accurate predictions are committed to incorrect global coordinates. The fundamental difference between transient sensor noise and persistent map corruption highlights why traditional noise and innovation filtering fail:

* **Transient Sensor Noise**: High-frequency, zero-mean fluctuations in local measurements. Because these errors do not correlate over time, standard recursive spatial averaging or statistical noise filters naturally cancel them out across successive observational passes.
* **Persistent Map Corruption**: Coherent, spatially misregistered updates caused by drift. These writes commit structurally plausible flow features into incorrect map cells. Rather than averaging out, repeated misregistered updates accumulate into coherent, persistent **ghost structures**—nonexistent physical features anchored into the global memory state.

Crucially, traditional innovation filtering mechanisms (such as Extended Kalman Filter innovation gates) fail to suppress ghost structures. Because aliased local observations are structurally plausible and locally consistent with internal sensor noise models, they yield small innovation residuals even at the drifted pose $\hat{p}_t$. Consequently, misregistered patches pass traditional innovation gates and are written directly into global memory.

Worse, an evolving map serves as the baseline reference for subsequent local updates. Once ghost structures are committed to global memory, they act as faulty spatial references, corrupting future observation-to-map alignment steps and triggering a self-reinforcing cascade of systemic failure.

### 3. The Solution: Map-Reference-Aware Conservative Fusion Framework

To prevent ghost structure accumulation, Jin et al. developed a map-reference-aware conservative fusion framework that decouples local patch prediction from global write permission.

```
                                  +-----------------------+
                                  |   Sensing Input (o_t) |
                                  |  (Pressure & Velocity)|
                                  +-----------+-----------+
                                              |
                                              v
+-----------------------+         +-----------+-----------+
| Evolving Global Map   |-------> | Map Reference Sampling|
| State M_(t-1)         |         |   (Ũ_map, c_map)      |
+-----------------------+         +-----------+-----------+
                                              |
                                              v
                                  +-----------+-----------+
                                  | Recurrent Input Vector|
                                  |  r_t = [z_π, z_v, ...] |
                                  +-----------+-----------+
                                              |
                                              v
                                  +-----------+-----------+
                                  |   Shared Recurrent    |
                                  |      State (GRU)      |
                                  +-----------+-----------+
                                              |
                   +--------------------------+--------------------------+
                   |                                                     |
                   v                                                     v
     +-------------+-------------+                         +-------------+-------------+
     | Patch Predictor Head      |                         | Write-Safety & Quality Heads|
     | (Velocity Patch μ_hat_t)  |                         |  (Score κ_t, Quality q_t)   |
     +-------------+-------------+                         +-------------+-------------+
                   |                                                     |
                   +--------------------------+--------------------------+
                                              |
                                              v
                                  +-----------+-----------+
                                  | Effective Reliability |
                                  |    Rule (κ_eff_t)     |
                                  +-----------+-----------+
                                              |
                                              v
                                  +-----------+-----------+
                                  | Attenuated Map Update |
                                  |      (Ω_t, Ψ_t)       |
                                  +-----------------------+
```

#### Sensing Architecture
The onboard observation vector $o_t = (\pi_t, U^{of}_t)$ combines two complementary sensory modalities:
* A 4-channel piezoresistive pressure array $\pi_t \in \mathbb{R}^4$.
* A $3 \times 3$ optical-flow velocity stencil $U^{of}_t \in \mathbb{R}^{2 \times 3 \times 3}$ captured from onboard vision.

#### Map Reference & Discrepancy
The global map state $M_t = (\Omega_t, \Psi_t)$ tracks the estimated 2D velocity field $\Omega_t : \mathcal{D} \to \mathbb{R}^2$ and accumulated spatial evidence confidence $\Psi_t : \mathcal{D} \to [0, 1]$. Over the local stencil footprint $F_t = F(\hat{p}_t)$, the framework samples the local map confidence $c^{map}_t$ and velocity stencil $\tilde{U}^{map}_t$:

$$c^{map}_t = \frac{1}{|F_t|} \sum_{(x,y) \in F_t} \Psi_{t-1}(x, y)$$

$$\tilde{U}^{map}_t = \begin{cases} Q_v(\Omega_{t-1}, \hat{p}_t), & c^{map}_t > \tau_\Psi \\ U_\emptyset, & c^{map}_t \le \tau_\Psi \end{cases}$$

Here, $Q_v$ samples the velocity map at the reported pose, $\tau_\Psi = 0.3$ is the map-evidence threshold, and $U_\emptyset$ is a learned null token. Representing unmapped areas with $U_\emptyset$ ensures that a lack of prior map evidence is treated as an absent reference rather than an active velocity disagreement.

#### Model Architecture & Recurrent Feature Input
* **Encoders**: Pressure measurements $\pi_t$ are processed by MLP encoder $\phi_\pi$, while onboard stencil $U^{of}_t$ and map stencil $\tilde{U}^{map}_t$ share MLP encoder $\phi_v$ (both architectures: $D_{in} \to 64 \to 64 \to 32$). Encodings are extracted as $z_{\pi t} = \phi_\pi(\pi_t)$, $z_{vt} = \phi_v(U^{of}_t)$, and $\tilde{z}_{vt} = \phi_v(\tilde{U}^{map}_t)$.
* **Discrepancy Feature**: Computed as $d_t = c^{map}_t |z_{vt} - \tilde{z}_{vt}|$.
* **Concatenated Recurrent Input Vector**: The input vector $r_t$ fed into the recurrent core explicitly integrates sensing encodings, reference discrepancy, normalized reported pose, and local map confidence:
  $$r_t = [z_{\pi t}, z_{vt}, \tilde{z}_{vt}, d_t, \bar{p}_t, c^{map}_t]$$
  where $\bar{p}_t \in [0,1]^2$ represents the reported pose $\hat{p}_t$ normalized componentwise by the domain dimensions.
* **Recurrent Core & Decoder**: A single-layer Gated Recurrent Unit (GRU) with a hidden dimension of $D_h = 96$ processes $r_t$, preserving temporal alignment context. An $8 \times 4 \times 4$ fully connected projection followed by two transposed-convolution layers ($8 \to 16 \to 2$) decodes the hidden state into a local velocity patch prediction $\hat{\mu}_t \in \mathbb{R}^{2 \times 21 \times 21}$. Auxiliary heads predict a patch informativeness score $q_t \in [0, 1]$ and the learned write-safety score $\kappa_t \in [0, 1]$.

#### Effective Reliability Rule and Pointwise Update Formulas
To balance early map initialization against late-stage update attenuation, the framework applies an effective write-reliability rule:

$$\kappa^{eff}_t = (1 - c^{map}_t) + c^{map}_t \kappa_t$$

When operating in unmapped territory ($c^{map}_t \le \tau_\Psi$), $\kappa^{eff}_t \ge 1 - \tau_\Psi = 0.7$, ensuring the system can freely initialize new map regions. As accumulated map evidence $c^{map}_t$ increases, $\kappa^{eff}_t$ shifts smoothly toward the learned write-safety score $\kappa_t$, continuously attenuating updates if spatial alignment is uncertain.

The predicted patch $\hat{\mu}_t$ is splatted at the reported pose to yield $\tilde{\mu}_t = \Pi(\hat{\mu}_t; \hat{p}_t)$. With patch support mask $m_t(x,y)$, the cellwise write mass is calculated as:

$$w_t(x, y) = m_t(x, y) q_t \kappa^{eff}_t$$

Pointwise recursive map updates for velocity $\Omega_t$ and evidence confidence $\Psi_t$ are then evaluated explicitly across all grid coordinates $(x,y)$:

$$\Omega_t(x, y) = \frac{\Psi_{t-1}(x,y)\Omega_{t-1}(x,y) + w_t(x,y)\tilde{\mu}_t(x,y)}{\Psi_{t-1}(x,y) + w_t(x,y) + \epsilon}$$

$$\Psi_t(x, y) = \text{clip}_{[0,1]} \left( \Psi_{t-1}(x,y) + w_t(x,y) \right)$$

Evidence saturation via clipping limits visit-count dominance while retaining the capability of later reliable observations to modify the map.

#### Loss Targets and Two-Stage Training Strategy
Supervision targets are defined via ground-truth alignment error $e_t = \|\hat{p}_t - p^\star_t\|_2$:
1. **Alignment Reliability Target**: $\kappa^{align}_t = \exp(-e_t / \sigma_\kappa)$ with spatial decay scale $\sigma_\kappa = 5.0\text{ px}$.
2. **Patch Informativeness Target**: $q^\star_t = 0.3 q_{sup,t} + 0.7 q_{struct,t}$, where $q_{sup,t}$ is the valid support fraction of the patch and $q_{struct,t} \in [0,1]$ is derived from the normalized vector patch gradient magnitude.

Jin et al. implement a **two-stage training strategy**:
* **Stage 1**: Encoders ($\phi_\pi, \phi_v$), shared GRU, and all prediction/gating heads are trained jointly using composite loss $L_{S1} = \lambda_{rec}L_{rec} + \lambda_{\Delta p}L_{\Delta p} + \lambda_\kappa L_\kappa + \lambda_{patch}L_{patch} + \lambda_q L_q$.
* **Stage 2**: Encoders, patch-decoder weights, and the sensor-reconstruction head are frozen. The GRU and the pose, reliability, and quality heads remain trainable. Crucially, the patch loss $L_{patch}$ is retained during Stage 2; retaining $L_{patch}$ ensures that fine-tuning the recurrent state for reliability calibration does not distort or degrade the latent flow patch representation.

#### Computational Footprint
The entire neural architecture consists of only **105.8k parameters**. When deployed on embedded edge hardware (a Raspberry Pi 5), the model executes a full prediction and fusion step in **$12.4 \pm 2.1\text{ ms}$**, making it highly practical for real-time robotic control loops.

### 4. Empirical Evaluation & Quantitative Benchmarks

#### Synthetic Benchmark Setup
Jin et al. evaluated their framework across four 3m $\times$ 1m FluidX3D simulation environments representing distinct flow fields: *Single Jet*, *Double Jet*, *Single Jet + Crossflow (CF)*, and *Double Jet + Crossflow (CF)*. Crossflow variants introduce strong background advection and severe spatial ambiguity. Performance was evaluated using four primary metrics:
* **Ghost Score**: Dimensionless metric quantifying false velocity artifacts committed to unmapped or low-flow background regions (lower is better).
* **NRMSE**: Normalized root-mean-square error over supported map regions (lower is better).
* **Active-Flow Coverage (ActCov)**: Retention fraction of true active flow regions relative to ungated mapping (higher is better).
* **Write Ratio (WR)**: Ratio of committed write mass relative to ungated mapping (lower indicates more conservative writing).

#### Hardware Replay Validation
To evaluate zero-shot transfer, the authors deployed the simulation-trained model without fine-tuning to a $3\text{m} \times 1\text{m}$ physical water tank testbed. A submerged U5 thruster generated a turbulent jet wake, while a robot platform collected 4-channel pressure data and optical-flow velocity stencils via an OV9281 camera. Planar Particle Image Velocimetry (PIV) served as ground truth.

Replaying sensor logs under injected localization drift demonstrated successful zero-shot transfer to physical hardware:
* **Ghost contamination dropped by 39%** (Ghost score reduced from 0.28 in No-Gate to 0.17 in the proposed method).
* **81% active map coverage was retained**, leaving uncertain, misaligned boundary regions unsupported rather than committing misregistered updates.

#### Mechanistic Insights & Ablation Methodology
The learned reliability score $\kappa_t$ exhibits a strong negative Pearson correlation (**$r = -0.63$**) with realized spatial alignment error $e_t$. As localization drift grows, the model automatically lowers $\kappa_t$, proving that the gate tracks alignment risk dynamically rather than acting as a static weight filter.

To evaluate architectural components fairly, Jin et al. applied a strict experimental control during ablation: **each ablation variant's cellwise write mass was scaled via a global bisection factor to force its Write Ratio (WR) to match the full model ($\text{WR} \approx 0.451$)**. This control guarantees that performance variations reflect *where* write mass is allocated rather than *how much* total mass is written.

| Variant | Ghost Score ($\downarrow$) | Write Ratio (WR) | NRMSE ($\downarrow$) | Active Coverage (ActCov $\uparrow$) |
| :--- | :---: | :---: | :---: | :---: |
| **Ours (Full Model)** | **$0.263$** | $0.451$ | **$0.197$** | **$0.540$** |
| **No Map Conditioning** | $0.304$ | $0.455$ | $0.232$ | $0.515$ |

Removing the recurrent GRU state caused the largest performance collapse (Ghost score increased to $0.337$), proving that temporal tracking of alignment evidence is essential for evaluating write safety. Removing map conditioning degraded the Ghost score to $0.304$, while removing the informativeness head $q_t$ caused the largest loss in active-flow coverage ($\text{ActCov}$ dropped to $0.502$).

### 5. Implications for AI Safety and System Design

The findings of Jin et al. offer three key takeaways for researchers and practitioners building persistent memory systems exposed to degraded feedback:

1. **Gating Memory Writes Under Degraded Feedback**:
   Systems that stream incoming sensory estimates directly into persistent global memory are highly vulnerable to silent corruption. When sensory inputs are spatially or semantically aliased, memory writes must be conditioned on explicit write-safety gating to prevent misregistered updates from permanently corrupting global state representations.

2. **Decoupling Content Prediction from Write Safety**:
   Predicting *what* information an observation contains (content generation/patch prediction) must be architecturally separated from evaluating *whether* that information is safe to commit to global state (write-safety gating). A locally accurate prediction can still be globally destructive if written under spatial misalignment.

3. **Graceful Degradation via Coverage-Precision Trade-offs**:
   Under severe feedback degradation or localization drift, maintaining high precision requires accepting partial memory coverage. Leaving uncertain spatial regions unsupported or unwritten preserves the structural integrity of existing global memory, preventing catastrophic failure cascades caused by self-reinforcing ghost structures.

In spatially ambiguous, drift-prone environments, write-safety gating is mandatory to prevent streaming memory architectures from succumbing to self-reinforcing map corruption.
